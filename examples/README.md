This folder contains several examples on how to use the library.

We currently have 3 examples:
- **Basic**: Shows a minimal implementation of the library. You can spawn the multiblock using an item and it will remove itself when it's complete.
- **Advanced**: Implements a full placement system using a schematic item. Uses a lot of the provided functions.
- **Custom Block**: Uses the additional conditions to make a multiblock that requires a custom block to complete.

> [!NOTE]
> These examples are purely for educative purposes and shouldn't be used to implement features in your own datapack. Many of the edge-cases haven't been fixed. They lack some real optimization and polishing
